# Ответы на вопросы методички

## Лабораторная работа № 2

1. В `ConfigDict` опция `extra="ignore"` отбрасывает незаявленные поля, `alias_generator=to_camel` формирует имена JSON-полей в camelCase, `populate_by_name=True` разрешает принимать имя Python и псевдоним. `from_attributes=True` позволяет читать данные из атрибутов объектов, например ORM-моделей.
2. `Field` задаёт ограничения и метаданные поля. `description` и `examples` попадают в JSON Schema и Swagger, `default` задаёт значение при отсутствии поля, а `ge=1` запрещает числа меньше единицы. `init_var` и `kw_only` относятся к инициализации dataclass.
3. `Path` описывает параметр пути, его ограничения и документацию. Для `/post/{post_id}` FastAPI преобразует сегмент пути в целое число, а ограничение `ge=1` отклоняет ноль и отрицательные значения с HTTP 422.

## Лабораторная работа № 3

1. В `SettingsConfigDict` параметр `env_file=".env"` указывает файл настроек, `env_file_encoding="utf-8"` задаёт его кодировку, а `extra="ignore"` позволяет использовать общий файл с переменными, которых нет в классе настроек. Переменные окружения процесса имеют приоритет над значениями файла.
2. В `mapped_column` первый аргумент задаёт тип SQL, `primary_key` включает столбец в первичный ключ, `autoincrement` включает автоматическую генерацию числового ID, `nullable` определяет допустимость SQL NULL, `unique` создаёт ограничение уникальности, а `index` объявляет индекс. `default` срабатывает при вставке через SQLAlchemy, `server_default` задаёт значение по умолчанию на стороне БД. `comment` сохраняет описание в схеме БД, `sort_order` определяет порядок объявления столбцов при генерации таблицы.
3. `echo` включает журнал SQL-запросов SQLAlchemy. Он помогает отлаживать запросы и транзакции. В проекте `SQL_ECHO` выключен по умолчанию, а `hide_parameters=True` скрывает значения параметров.

## Лабораторная работа № 4

1. Удаление refresh-токена удаляет связанную строку access-токена по внешнему ключу `ON DELETE CASCADE`. Подпись выданного JWT по-прежнему проходит математическую проверку до истечения срока, но приложение отклоняет токен сразу, поскольку активной записи в БД больше нет.
2. Наследование от `str` делает члены `RegexEnum` совместимыми со строковым API. При этом значения остаются перечислением. В `Field(pattern=…)` используется `.value`, чтобы передать шаблон в виде обычной строки.
3. `TokenController` выпускает пару токенов по общим правилам для входа и обновления. `AuthorizationController` проверяет логин и пароль, а `AuthenticationController` проверяет сеанс, обновляет пару и выполняет выход. Выделение выпуска токенов устраняет дублирование TTL, создания записей и подписи JWT.
