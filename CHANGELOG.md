# Ответы на вопросы методички

## Лабораторная работа № 2

1. В `ConfigDict` опция `extra="ignore"` отбрасывает незаявленные поля, `alias_generator=to_camel` формирует имена JSON-полей в camelCase, `populate_by_name=True` разрешает принимать имя Python и псевдоним. `from_attributes=True` позволяет читать данные из атрибутов объектов, например ORM-моделей.
2. `Field` задаёт ограничения и метаданные поля. `description` и `examples` попадают в JSON Schema и Swagger, `default` задаёт значение при отсутствии поля, а `ge=1` запрещает числа меньше единицы. `init_var` и `kw_only` относятся к инициализации dataclass.
3. `Path` описывает параметр пути, его ограничения и документацию. Для `/post/{post_id}` FastAPI преобразует сегмент пути в целое число, а ограничение `ge=1` отклоняет ноль и отрицательные значения с HTTP 422.
